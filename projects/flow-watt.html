Flow Watt

A mobile-first energy tracking product focused on visual clarity, trend comparison, and reusable UI primitives for data-heavy screens.

Live demo

Case Study Summary

  • Problem: Energy data often looks complex and discourages regular use.
  • Audience: Users who need a quick understanding of household energy trends.
  • Role: Product and frontend implementation lead.
  • Scope: Cross-platform app views and dashboard interactions.
  • Timeline: 2025 to present; active repository updates in 2026.
  • Stack: React Native, React, TypeScript, Firebase hosting for web delivery.
  • Release surfaces: Web demo plus shared mobile-first architecture for Android and iOS clients.
  • Constraints: Keep charts readable on mobile while retaining useful granularity.
  • Technical decisions: Reusable card and chart modules with typed data contracts to reduce feature-level divergence.
  • Results: 1 public web deployment, typed dashboard modules reused across core screens, and one consistent interaction model across data views.
  • Public metrics note: User/download counts are not published; this page reports only verifiable implementation scope.
