Guess What - Movie

A browser game inspired by an in-office activity, designed for quick setup, short rounds, and repeatable social play.

Live demo

Case Study Summary

  • Problem: Group games often require too much setup for casual sessions.
  • Audience: Friends, teams, and meetups looking for a quick ice breaker.
  • Role: Product ideation and implementation.
  • Scope: Web gameplay loop, clue rendering, score-friendly rounds.
  • Timeline: Created in 2026 and iterated through additional releases.
  • Stack: React, TypeScript, Firebase hosting.
  • Release surfaces: Public web deployment with a browser-first gameplay loop for desktop and mobile browsers.
  • Constraints: Gameplay had to be understandable in seconds without onboarding text walls.
  • Technical decisions: Simple interaction model prioritized over complex state features to keep latency and cognitive load low.
  • Results: 1 public live demo, active source repository, and repeatable round mechanics designed for quick group sessions.
  • Public metrics note: User/session counts are not published; this page reports only verifiable implementation scope.
