Kylis

Kylis (formerly Smart Fridge) is a shared fridge and shopping list app that tracks expiry dates, suggests what to cook and buy, and keeps a whole household on the same list.

Live demo (opens in new tab)

Case Study Summary

  • Problem: Households lose track of what is in a shared fridge, so food expires unused and duplicates get bought.
  • Audience: Families, partners and flatmates sharing one kitchen, starting in Sweden.
  • Role: Solo engineer, end to end.
  • Scope: Expiry tracking with category shelf-life defaults, barcode scanning (product names from Open Food Facts), receipt-photo entry, a shopping list that suggests low-stock and soon-to-expire items, AI recipe generation from what is in the fridge (prioritizing items about to expire, respecting diets and allergies), saved favourites, reminders, and household sharing via invite code.
  • Timeline: Repository created 2024-11-11 and maintained through 2026.
  • Stack: React Native, TypeScript.
  • Release surfaces: iOS and Android (App Store and Google Play launch coming soon), from a single codebase.
  • Highlight: Recipe generation turns the live inventory into cooking ideas, so expiring items get used first and a recipe's missing ingredients can be added to the shared shopping list in one tap.
  • Languages: Swedish, English and Chinese, with shelf-life defaults for every category.
  • Constraints: Fast item input on mobile and low-friction daily upkeep, plus a free guest mode (30 items, 20 list entries, 10 scans) before sign-in with Apple or Google.
  • Technical decisions: Typed item states and expiry fields to support colour-coded fresh/soon/expired status, predictable filtering and reminders; one shared inventory per household.
  • Results: Single-repository app, explicit lifecycle states for active/use-soon/expired items, and an implementation timeline spanning 2024-2026.
  • Public metrics note: User/download counts are not published; this page reports only verifiable implementation scope.

This project is documented as a practical case study of Kylis, formerly Smart Fridge, so the implementation context is citable even while repository visibility is private.
